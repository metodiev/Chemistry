# Terminology Rules

Consistent terminology is not cosmetics. A student who meets "mass" used for "amount
of substance" in one chapter and correctly in the next will form a misconception that
survives examinations.

---

## 1. Mandatory distinctions

| Do not confuse | Correct usage |
|---|---|
| Mass vs amount of substance | $m$ in g or kg; $n$ in mol. "One mole of water has a mass of 18.02 g", never "one mole weighs 18.02 g" in formal text. |
| Concentration vs amount | $c = n/V$; a "0.1 mol dm⁻³ solution" is not "0.1 moles". |
| Heat vs enthalpy vs internal energy | $q$ is a transfer of energy across a boundary; $H$ and $U$ are state functions. |
| Temperature vs heat | A spark at 2000 °C contains little energy; a bathtub at 40 °C contains a lot. |
| Strong vs concentrated | Strong = fully dissociated; concentrated = large $c$. |
| Weak vs dilute | Weak = partially dissociated; dilute = small $c$. |
| Accuracy vs precision | Accuracy = closeness to truth; precision = reproducibility. |
| Oxidation vs combustion | Combustion is a specific, usually rapid, oxidation with $\ce{O2}$. |
| Atomic mass vs molar mass | Relative atomic mass is dimensionless; molar mass has units g mol⁻¹. |
| Empirical vs molecular formula | $\ce{CH2O}$ vs $\ce{C6H12O6}$. |
| Orbit vs orbital | Orbit is a classical trajectory (obsolete for electrons); orbital is a wavefunction. |
| Shell vs subshell vs orbital | $n$ / $l$ / $m_l$. |
| Equivalent vs mole | Equivalents depend on the reaction; moles do not. |

---

## 2. Naming policy

1. **Systematic IUPAC name first**, with the common name in parentheses on first
   use: "ethanoic acid (acetic acid)", "propan-2-one (acetone)".
2. **Preferred IUPAC Name (PIN)** is used where IUPAC 2013 defines one; where the
   retained name is the PIN (e.g. acetic acid), that name is used.
3. **Trivial names** are retained only for substances whose systematic name is never
   used in practice: water, ammonia, methane, benzene, glucose.
4. **Historical names** are marked *(obsolete)* or *(discouraged)*, never silently
   replaced, because students will meet them in the literature.

---

## 3. Capitalisation and formatting

| Item | Rule | Example |
|---|---|---|
| Element names | lower case | sodium, not Sodium |
| Element symbols | first letter capital, second lower | $\ce{Na}$, $\ce{Cl}$, never $\ce{NA}$ or $\ce{CL}$ |
| Compound names at sentence start | capitalise normally as a word | "Sodium chloride dissolves…" |
| Units | upright, space before, no plural | $5.0\ \mathrm{mol}$, not 5.0 mols |
| Degree Celsius | space before °C | $25.0\ \mathrm{^\circ C}$ |
| pH, pKa | lower-case p, italic subscript a | $\mathrm{p}K_\mathrm{a}$ |
| Named laws | lower case except the name | Boyle's law, Le Châtelier's principle |
| Named reactions | capitalised as proper nouns | Diels–Alder reaction, Grignard reagent |
| En-dash | between names in named reactions | Zaitsev, Markovnikov, Wittig |

## 4. Symbols

| Quantity | Symbol | Notes |
|---|---|---|
| amount of substance | $n$ | mol |
| molar mass | $M$ | g mol⁻¹ |
| relative atomic mass | $A_\mathrm{r}$ | dimensionless |
| relative molecular mass | $M_\mathrm{r}$ | dimensionless |
| standard enthalpy change | $\Delta H^\circ$ | J mol⁻¹ |
| standard Gibbs energy change | $\Delta G^\circ$ | J mol⁻¹ |
| equilibrium constant | $K$ | dimensionless; $K_c$, $K_p$ variants |
| acid dissociation constant | $K_\mathrm{a}$ | dimensionless in modern usage |
| solubility product | $K_\mathrm{sp}$ | dimensionless (activities) |
| standard electrode potential | $E^\circ$ | V |
| rate constant | $k$ | units depend on order |
| wavelength | $\lambda$ | m |
| wavenumber | $\tilde{\nu}$ | cm⁻¹ (conventional in IR) |
| chemical shift | $\delta$ | ppm |

## 5. Spelling convention

The repository uses **Oxford British English**:

- **-ize / -yze**, not -ise / -yse: ionize, catalyze, hydrolyze, organize, summarize,
  analyze.
- **-our**: colour, behaviour, vapour, favours.
- **-re**: centre, metre, litre, fibre.
- **-ce** for nouns, **-se** for verbs: licence (noun) / license (verb), defence.
- **Doubled l** before a suffix: labelled, modelling, cancelled.
- Chemical terms follow IUPAC spelling regardless: *sulfur* (not sulphur),
  *aluminium* (IUPAC), *caesium* (IUPAC).

---

## 6. Numbers and units in prose

- Write out numbers below ten in prose ("three experiments"), use digits for
  measurements ("3.0 g").
- Never start a sentence with a numeral; rewrite ("A total of 25 samples…").
- Use the multiplication sign × between a number and a power of ten:
  $6.02 \times 10^{23}$.
- Use a thin space or no space as thousands separator, never a comma, in SI contexts:
  $22\,414\ \mathrm{cm^3}$ or $22414\ \mathrm{cm^3}$.
- Use $\approx$ only for genuine approximations, not for "approximately exact".
