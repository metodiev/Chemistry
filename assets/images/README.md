# Images

Raster and photographic assets: electron micrographs, photographs of apparatus,
instrument output, and plots that Mermaid cannot draw.

## Rules

- **SVG first.** Use PNG or JPEG only for genuinely raster content (micrographs,
  photographs, scanned spectra).
- **Resolution.** Minimum 1200 px on the long edge for anything intended to be read;
  target 150 dpi at final print size.
- **Accessibility.** Every image must have alt text in the chapter that uses it,
  describing what the image shows rather than merely naming it.
- **Colour.** Do not rely on red/green contrast alone; use shape or brightness as well.
- **Provenance.** Every file gets a row in the table below before it is merged.

## What must not be uploaded

- Figures copied from textbooks, journals, or websites without written permission.
- Screenshots containing personal data, unpublished results, or instrument serial
  numbers.
- Images of identifiable people without consent.

If you are unsure whether an image may be reused, do not add it. A missing figure is a
minor gap; a copyright violation is not.
