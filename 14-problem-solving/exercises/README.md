## How to use a bank

1. Work through it **after** the chapters, not before.
2. Time yourself: one mark per minute is a reasonable pace for Level 2 and above.
3. Mark your own work using the rubric in
   [assessment-guide.md §2.3](../../00-learning-guide/assessment-guide.md#23-marking-your-own-work).
4. Classify every error (K/M/A/U/R) and log it. See
   [assessment-guide.md §2.1](../../00-learning-guide/assessment-guide.md#21-error-classification).
