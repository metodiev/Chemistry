# Solutions — Index

Full worked solutions for every exercise bank.

## What a solution contains

Each solution gives, in this order:

1. **Strategy** — one or two sentences naming the relationship to be used.
2. **Working** — the algebra in symbols, then the substitution with units.
3. **Answer** — the value with significant figures and units.
4. **Check** — a sanity check: order of magnitude, limiting case, or an independent
   route to the same answer.
5. **Where marks are lost** — the specific error this problem is designed to catch.

A solution that gives only the final number is considered incomplete and will be
rejected in review.

## Using solutions honestly

- Read the **strategy line only** if you are stuck, then close the file.
- If you needed the full solution, redo the problem from scratch after 48 hours.
- If you disagreed with a solution, open a `correction` issue with your reasoning.
  Genuine ambiguities are fixed; wrong solutions are fixed faster.
